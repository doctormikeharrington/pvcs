Add the Psychiatry app to your home screen

One-time setup — takes about 20 seconds.

iPhone / iPad (Safari)

  1. Make sure this page is open in Safari.
  2. Tap the Share button (square with an up-arrow). On iOS 26, tap ⋯ at the bottom right first, then Share.
  3. Scroll down and tap Add to Home Screen (tap View More if you don't see it).
  4. If there's an Open as Web App switch, turn it off.
  5. Tap Add.

Turning “Open as Web App” off makes the icon open in Safari, where you're already signed in to Google.

Android (Chrome)

  1. Make sure this page is open in Chrome.
  2. Tap the ⋮ menu at the top right.
  3. Tap Add to home screen, then Add (choose Create shortcut if asked).
